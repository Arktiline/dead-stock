## Projekti tutvustus

**Dead Stock** on tehasehaldusmäng, mis keskendub illegaalse rahatrükkimise skeemi ülesehitamisele ja juhtimisele.

Sinu ülesandeks on arendada oma tehast, hallata tootmisprotsesse, kaitsta operatsiooni politsei eest ning toota võimalikult kvaliteetset võltsraha.
