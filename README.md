# Dead Stock

**Dead Stock** on mäng, mis keskendub illegaalse rahatrükkimise skeemi ülesehitamisele ja haldamisele. Sinu ülesandeks on juhtida oma tehast, kaitsta operatsiooni politsei eest ning toota võimalikult kvaliteetset võltsraha.
